# PRH — Patent- ja rekisterihallitus (Finland)

## API
- **Base:** `https://avoindata.prh.fi`
- **Y-tunnus:** `/ytunnus/`
- **Verohallitus (skatteverket):** `/verohallinto/`

## Data typer
| Typ | Data |
|---|---|
| Y-tunnus | 7-siffrig + 1 kontrollsiffra |
| Tilinpäätös | Årsredovisning |
| Luotonhakija | Kreditupplysning |

## Auth
Publikt. API-nyckel behövs för vissa endpoints.
